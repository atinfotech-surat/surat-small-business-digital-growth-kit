# Monthly digital check-up

A 30–45 minute routine for a small team. The goal is to make one informed improvement—not to collect every possible metric.

## 1. Set the context

- Business / location: ______________________________
- Period reviewed: __________________________________
- Compared with: ___________________________________
- Promotions, holidays, closures, or other changes: ______________________
- Person completing this review: ____________________

Use like-for-like periods where practical. A festival week, seasonal closure, or one-off campaign can make month-to-month comparisons misleading.

## 2. Choose up to five useful measures

Use measures that connect to your goal. Leave a row blank if you do not have reliable data.

| Measure | Previous period | This period | What changed / source |
|---|---:|---:|---|
| Qualified enquiries received | | | |
| Bookings / quote requests / orders | | | |
| Calls or WhatsApp conversations attributed to marketing | | | |
| Website contact-form submissions | | | |
| Store visits or direction requests, if available | | | |
| Repeat customers or referrals, if tracked | | | |
| Response time to new enquiries | | | |
| Revenue from a trackable campaign, if measured reliably | | | |

Do not treat follower count or total page views as success by themselves. Pair attention measures with an action that matters to the business. Keep customer-level records private; share only aggregated numbers publicly.

## 3. Review the path from discovery to action

- Which source brought the most useful enquiries? (website, referral, local search, social, walk-in, other)
- Which page or post helped customers decide?
- What questions did people ask more than once?
- Where did a visitor or enquiry get stuck?
- Did every call, message, form, or booking reach the right person?
- Was any information outdated—hours, price, availability, location, or delivery?

## 4. Choose one small experiment

Write an action that can be completed in two weeks. Change one thing at a time where possible.

- **Observation:** ______________________________________________
- **Action to test:** ____________________________________________
- **Who owns it:** __________________ **Due date:** ______________
- **How we'll know if it helped:** _______________________________
- **When we'll review:** ________________________________________

Examples: clarify a service page's next step; add current product photos; update holiday hours; reply faster to enquiries; publish one useful FAQ; ask customers neutrally for feedback.

## 5. Close the loop

- What should we keep doing? ____________________________________
- What should we stop or simplify? ______________________________
- What needs an owner next month? _______________________________
- Are all published claims and photos still accurate and approved? Yes / No

## Notes on interpretation

Digital performance is affected by seasonality, customer demand, location, budgets, platform changes, and many other factors. Record what you changed and avoid claiming a campaign caused a result unless the data supports that conclusion.
